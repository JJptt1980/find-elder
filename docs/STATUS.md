# 尋找大長老：目前狀態

最後更新：2026-11-20

## 目前進度
- 三種玩法：尋寶、好吃的、私房地圖。公開網址 https://jjptt1980.github.io/find-elder/ （push main 由 GitHub Actions 部署）。
- 新增：尋寶集滿七顆後播「召喚演出」：畫面變暗、出現星星、浮出兩句字，接著畫面搖晃、手機由短到長震動加低頻地鳴，白光一閃後顯示「第 N 話」標題卡，最後是結局。可以按「跳過」。
- 四種結局照順序輪流（不是隨機）：
  1. 小內褲 🩲 晃著飄下來：「你的願望已經實現了。」
  2. 「您召喚的對象目前不在服務區，請稍後再撥。」七個 ✨ 飛散
  3. 大長老看見你的潛力：顯示戰鬥力（直線估算走了幾公尺）、花了多久、第幾輪破關
  4. 演最久，結果只有 🐢 爬過去：「……就這樣。」
- 第一次湊滿四種結局時，額外顯示「恭喜你湊滿了全部結局。如果有意見，請洽開發者。」（只出現一次）
- 破關紀錄存在手機的 localStorage `fe-saga`（rounds、next、seen）。

## 已定案的決定
- 七龍珠的梗只用文字和一般 emoji：不畫神龍、不放原作音效和龍珠圖案，冒出來的東西永遠不現身。
- 雷達外觀維持 DB-radar 原樣。
- 私房地圖「地球」「納美克星」各限 7 顆，第三組起自訂、不限數量。
- 不做 Share Target（vivo 陸版沒 Google 服務）、不做朋友雷達。
- 結局輪流出現，不隨機。
